# 更新记录

> 早期迭代的逐条记录已不可追溯，这里保留可确认的版本里程碑。

## 0.14.0 — 2026-11-16

**新增**
- 播放模式改为下拉菜单：顺序播放 / 列表循环 / 随机播放 / 单曲循环，当前模式带勾选标记
- 单曲循环真正重播当前曲目（此前只是「不放下一首」）
- 播放列表侧栏支持右键唤出菜单：**重命名**、删除列表
- 添加目录时显示扫描进度：走目录阶段报「已找到 N 首」，读标签阶段报「N / M」，两个窗口同步

**移除**
- 播放列表条目上的右键「删除歌曲」

**修复**
- 面板切换播放模式后按钮变了但实际播放行为不变（状态改动改由主窗口执行后再广播）

## 0.13.0 — 2026-11-16

**新增**
- 「关于」独立小窗：标题栏 ⓘ 入口，显示作者、邮箱与播放器简介
- 关于窗单例：重复点击只把已有窗口挪回主体正中并置顶
- 三条关闭路径：确定按钮 / Esc / 右上角关闭

**修复**
- 关于窗污染窗口布局表，导致下次启动多还原一个不该存在的窗口

## 0.12.0

**变更**
- 主体界面重构为「左频谱屏 + 右控制区」，频谱屏占满内容区
- 示波显示改为三种形态：条带 / 背景 / 关闭
- 收回旧版为条带额外预留的 26px 高度，老布局文件自动补偿一次

## 0.11.0

**新增**
- 示波带与背景示波两种显示形态
- 频谱柱与示波共用同一份 `AnalyserNode` 数据，跨窗口广播

## 0.10.0

**新增**
- 状态行（状态文字 + 进度）与状态提示
- 曲目信息展示：艺术家、列表序号、时长

## 0.9.0

**新增**
- 播放列表独立面板窗口
- 多列表并存，侧栏切换、新建、清空
- 添加文件 / 添加文件夹（递归扫描）

## 0.8.0

**新增**
- 十段均衡器窗口，31Hz – 16kHz，6 组预设
- 三套皮肤：经典紫罗兰、经典钢蓝、现代深色
- 窗口缩放手柄、双击复位

## 0.7.0

**新增**
- 歌词秀窗口，读取同名 `.lrc`，逐行高亮滚动

## 0.4.0

**首个可分发版本**
- 主体播放窗口、播放控制、进度与音量
- NSIS 安装包

---

## 版本号约定

- 版本号写三处，必须同步：`package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`
- 从二进制分发出去的是 `src-tauri/target/release/ttplayer.exe`，界面上的版本号取自 `tauri.conf.json`
